# LAPA — локальный PWA-прототип

Требуются Node.js 24 LTS и npm.

```sh
npm ci
npm run build
npm start
```

Откройте `http://localhost:3000` на машине, где выполняются команды. Для доступа с другого устройства и установки PWA нужен HTTPS-хостинг. Для разработки: `npm run dev`; offline и Service Worker проверяйте в production-режиме.

На первом запуске язык — иврит. Переключатель HE / EN / RU всегда вверху. Введите израильский номер: например, 050-123-4567. Опишите проблему, ответьте на демонстрационный вопрос, заполните адрес и отправьте заявку. Данные сохраняются в IndexedDB браузера.

Кабинет мастера: удерживайте логотип LAPA 7 секунд (также доступно удержание Enter или пробела на логотипе) → «Открыть демо-кабинет». Телефон и PIN не проверяются. Можно добавить примеры заявок либо обработать свою: принять → начать работу → работа выполнена. Вернитесь к клиенту через меню и подтвердите завершение.

Реально работают локальные сценарии, фото, черновики, история, календарь, настройки и offline после первого online-запуска. AI заменён явно подписанным демонстрационным адаптером. Supabase, серверная авторизация, WebAuthn, push, автоматическое закрытие через 24 часа, очистка PII через 90 дней и адресные справочники пока не подключены. Это не публичный сервис и не защищённая многопользовательская система.

Проверки: `npm test`, `npm run typecheck`, `npm run build`; при запущенном production-сервере — `npm run test:e2e`. В этой среде Playwright использует `/usr/bin/chromium`. Для другого компьютера путь настраивается в `playwright.config.ts`.

Подробности архитектуры и ограничений — в README.md.

## Публикация на GitHub Pages

Адрес приложения после успешного deployment: `https://satorimen.github.io/LAPA/`.

В репозитории GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` собирает приложение и публикует его при обновлении ветки `main`. Можно также открыть **Actions → Deploy LAPA to GitHub Pages → Run workflow**.

Для локальной статической сборки:

```sh
npm ci
npm run build:pages
```

Готовый сайт находится в `out/`. Команда учитывает `/LAPA/`, включая картинки, шрифты, manifest и Service Worker. Для другого имени репозитория задайте `NEXT_PUBLIC_BASE_PATH=/ИмяРепозитория` и измените то же значение в workflow. Для корневого домена используйте пустое значение. Статическая сборка не требует Node.js на хостинге, но в ней по-прежнему нет сервера, AI, push или общей базы данных.
